# معجم لتجارة الدواجن

## الروابط بعد النشر

- إدارة أرقام العملاء والسقوف والتوقيف:
  `/customers.html`
- رفع PDF وتحديث الأرصدة:
  `/pdf.html`
- الصفحة الرئيسية:
  `/`
- فحص الخادم وقاعدة البيانات:
  `/api/health`

## السلوك

واجهة `customers.html` تعرض العملاء الموجودين في قاعدة البيانات فقط، وتستخدم لإضافة أو تعديل رقم الهاتف والسقف والتوقيف. لا تنشئ عميلًا جديدًا.

واجهة `pdf.html` منفصلة لرفع كشف PDF؛ تضيف الأسماء الجديدة من الكشف وتحدث أرصدة العملاء، وتحفظ الاسم القادم من الكشف.

على Render استخدم:

- Build Command: `npm install`
- Start Command: `node server.js`
